# DilliVerse 3D 🏙️

A browser-based Delhi-inspired open-world prototype built with Three.js.

## New V4 content
- Delhi bus adda with platforms and parked buses
- Metro station and Delhi street market
- Jantar Mantar-inspired plaza and observatory landmark
- Fictional, peaceful public demonstration scene with crowd, placards, police cordon and barricades
- Crowd dispersal animation when the player enters the protest area (no graphic violence)
- Samosa stall with a short queue and coin-based snack interaction
- Bus conductor NPC and route dialogue
- Human-style procedural characters, animated pedestrians and moving Delhi-style traffic
- Collisions with NPCs, buildings, stalls, barricades and traffic

## V5 update
- **Working Delhi Metro:** elevated viaduct, two stations (Janakpuri West and Janakpuri East) with ramps, platforms, yellow safety line and a shuttle train with sliding doors
- **Real DMRC-style announcements** (English + Hindi, voice + subtitles + chime/door beeps): train arriving, mind the gap, doors closing, next station, which side the doors open
- Press **E** at the platform when the doors are open to board, ride to the next station, press **E** to get off
- Bigger city: longer road, wider map, extra buildings, moving traffic that stops for the player, drifting clouds
- Smoother character animation: speed-based walk cycle, arm swing, body bob, idle breathing, smooth turning, NPCs face you when you walk close

## Run
Open `index.html` in a modern browser with an internet connection (Three.js is loaded from jsDelivr CDN).

## Controls
- WASD / Arrow keys: move
- Shift: sprint
- Space: jump
- E: interact with nearby NPC
- Drag mouse: rotate camera
- Mobile: on-screen joystick, RUN and INTERACT

## GitHub Pages
Upload `index.html` and `README.md` to the repository root, then enable Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

This is an early playable prototype using procedural geometry rather than a full commercial 3D asset pack.
